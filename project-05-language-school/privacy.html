This is a portfolio concept project. When the server is running, a submitted name, phone number and selected lesson format are stored in a database and can be viewed by an administrator through the API and Tkinter app. In static preview mode, the form does not submit anything.

Please use fictional details when testing. No real educational service is provided. The deployment owner is responsible for retention and deletion of any records.
