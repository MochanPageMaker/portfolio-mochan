How to explore this demo

Quick preview—no password needed. If you see a login form, select “View demo without signing in” above it. On GitHub Pages, the preview opens automatically. Switch themes, explore charts, filter the table and download a CSV. The demo does not change server data.

Full local version. In the main project folder, run setup.bat once and create an administrator account. Then run start-server.bat, visit http://127.0.0.1:8080/ and open project 04. Sign in with the credentials you created. There is no shared default password.

  1. Overview: explore KPIs, revenue and the funnel. MRR means monthly recurring revenue from active subscriptions. The 3 / 6 months selector changes the revenue chart only.
  2. Customers: search by company, choose a status and sort the list. Export CSV downloads the currently filtered table.
  3. Theme: use the sidebar button to switch between light and dark modes.
  4. Users and settings: on the server, an administrator can create accounts, revoke access, rename the workspace and update its revenue goal. Analysts can view data and export CSV.

Edit charts and customers: run start-admin.bat, connect to the server and choose “Metric — SaaS”. After editing, select “Apply locally”, then “Publish changes to server” and refresh the dashboard.

All figures are illustrative. Use an HTTP server for local viewing; opening index.html directly will not load the data.
